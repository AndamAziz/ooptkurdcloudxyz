# Vulnerable road users, as screenshots

This chapter would not print to a PDF like the other thirteen, so it is here as one screenshot
per question: the question, its options with the right one marked, and the explanation.

Upload them all into this folder (Add file → Upload files; the browser takes the whole
selection at once). The order of the file names is the order of the questions, which is how a
screenshot is matched to the question it shows.

Like the PDFs, they are read here and then dropped from the branch: only the questions and
pictures taken out of them are merged.
