# Car chapter PDFs

The car theory test (category B) is what the course teaches, so the chapters are read from here.

Upload a chapter's PDF into this folder on GitHub (Add file → Upload files), on the working
branch rather than on `main`. The questions and pictures in it that the course does not have yet
are added to that chapter; nothing is ever removed, so a chapter keeps every question it already
has even if its PDF holds fewer.

The PDFs are read here and then dropped from the branch, so the repository is not left carrying
tens of megabytes that nothing reads again. Only the extracted questions and pictures are merged.
